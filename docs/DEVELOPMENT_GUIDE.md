# WeekLife 开发指南

## 项目架构

### 目录结构
```
lib/
├── common/           # 通用组件和工具
│   ├── ui/          # UI 相关（颜色、样式等）
│   └── utils/       # 工具类
├── data/            # 数据层
├── domain/          # 业务逻辑层
└── presentation/    # 表现层
    └── pages/       # 页面组件
```

### 设计系统
- **颜色**: 使用 `AppColors` 类统一管理
- **文字**: 使用 `TextStyles` 类统一管理
- **尺寸**: 使用 `SizeStyles` 类统一管理

### 组件规范
1. 所有自定义组件都应该有清晰的文档注释
2. 参数应该有合理的默认值
3. 组件应该支持主题定制

### 状态管理
- 使用适当的状态管理方案
- 避免过度复杂的状态结构
- 确保状态更新的性能

## 最佳实践

### 代码质量
- 遵循 Dart 官方代码规范
- 使用有意义的变量和方法名
- 保持方法简洁，单一职责

### 性能优化
- 合理使用 `const` 构造函数
- 避免在 `build` 方法中创建新对象
- 使用 `ListView.builder` 处理长列表

### 用户体验
- 提供适当的加载状态
- 友好的错误提示
- 流畅的动画过渡
